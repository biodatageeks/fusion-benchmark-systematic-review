# Edgren reference sets by sequencing run

Each CSV contains the events assigned to the cell line of the indicated SRA run. The folder name, filename, `truthset_size` and `truthset_id` identify the source reference set of 27, 38, 53 or 99 events across all four cell lines. Individual files contain fewer rows because they cover one cell line. Runs from the same cell line use the same list; assignment to a cell line does not establish that every event is present in a particular run.

These files preserve raw gene labels and source fields from the local source reconstruction; they are not the normalized matching tables used for scoring. Labels separated by `|` are retained as supplied and are not expanded into independent events. The 99-event list combines evidence from publications and other preparations of these cell lines. The 27- and 53-event source lists are [Edgren 2011 Table 1](https://link.springer.com/article/10.1186/gb-2011-12-1-r6/tables/1) and the [Haas FusionBenchmarking reference](https://github.com/fusiontranscripts/FusionBenchmarking/blob/master/cancer_cell_lines/Edgren_subset/edgren.truthset.raw); the 99-event list comes from the True Positives sheet in [Davidson 2015 Additional file 3](https://link.springer.com/article/10.1186/s13073-015-0167-x). NFS1-PREX1 in the 27-event list is described as tentative in Edgren 2011. The 53-event list is not fully nested in the 99-event list under the documented matching analysis.

`manifest.csv` records the number of events in each file. Do not sum its rows as independent events across runs: BT-474 and SK-BR-3 each have two runs.

The [38-pair reference](truthset_38/README.txt) is extracted from Rodríguez-Martín et al. (2017), *ChimPipe*, Additional file 1, Table S2, PDF page 3 ([DOI](https://doi.org/10.1186/s12864-016-3404-9)). The Edgren rows list 38 directed gene pairs and 42 junctions: BT-474 21 pairs, SK-BR-3 8, MCF-7 6 and KPL-4 3. These CSV files contain gene pairs, preserving the source symbols and direction. The main article Table 1 reports 40 pairs and 46 junctions; this export follows the actual S2 list without imputing missing events. These are incomplete positive references: unmatched predictions are not necessarily biological false positives.
