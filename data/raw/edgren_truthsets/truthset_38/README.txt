Edgren positive reference: ChimPipe Table S2 (38 gene pairs)

Source: Rodriguez-Martin et al. (2017), ChimPipe, doi:10.1186/s12864-016-3404-9.
Additional file 1, Table S2, PDF page 3, Edgren rows.

This export contains 38 ordered gene pairs across four cell lines:
BT-474: 21; SK-BR-3: 8; MCF-7: 6; KPL-4: 3.
The source contains 42 junctions; multiple junctions for the same pair are collapsed here.
The main article Table 1 reports 40 pairs / 46 junctions, which disagrees with the actual S2 list.
No missing events have been inferred or added. Original gene symbols are preserved.

Files use the existing csv_per_sample schema. Run-to-cell-line mapping follows the
existing manifest.csv. Both runs of a cell line receive the same reference list.
This assignment does not establish that each event is expressed in each run.
Do not sum rows across all six runs as independent biological events.
This is an incomplete positive reference set; unmatched calls are not necessarily biological false positives.
Genomic rearrangement validation is left blank because it was not extracted event by event.
